# 🐕 Flu's Abenteuer – Jump & Run

Ein browserbasiertes Jump-&-Run-Spiel mit dem Hund **Flu**. Sammle Münzen, weiche roten aus und aktiviere den Doppelpunkte-Bonus!

## 🎮 Spielprinzip

Du steuerst den Hund **Flu**, der automatisch durch die Welt läuft. Springe, um Münzen zu sammeln oder roten auszuweichen. Das Spiel dauert **80 Sekunden** – sammle so viele Punkte wie möglich!

## 🪙 Münzen

| Münze | Punkte | Effekt |
|-------|--------|--------|
| 🟡 Gelb | **+5** | Freundliches Pling |
| 🔴 Rot | **-10** | Tiefes Wah |
| 🌈 Bunt | – | **2× Punkte für 10 Sekunden** + Sirene |

## 🕹️ Steuerung

| Taste | Aktion |
|-------|--------|
| `Leertaste` | Springen |
| `↑ Pfeil` | Springen |
| `Mausklick` | Springen |

> **Doppelsprung möglich!** – einfach zweimal drücken.

## 🏆 Bestenliste

Die **Top 5 Highscores** werden lokal im Browser gespeichert und bleiben auch nach dem Schließen erhalten.

## 🔊 Sound

Alle Sounds werden direkt im Browser über die **Web Audio API** erzeugt – keine externen Dateien nötig.

- 🎵 Fröhliche 8-Bit-Hintergrundmelodie
- 🔔 Pling beim Einsammeln gelber Münzen
- 😩 Wah beim Einsammeln roter Münzen
- 🚨 Sirene während des 2×-Bonus

## 🚀 Starten

Einfach `flu_adventure.html` im Browser öffnen – fertig!

Keine Installation, keine Abhängigkeiten, keine Internetverbindung nötig.

## 🛠️ Technologien

- HTML5 Canvas
- Web Audio API
- Vanilla JavaScript
